Vehicles

Every vehicle in the roster, turned in the browser from the same baked files the game loads. Each has a full review page: reference against model, LODs against their budgets, damage states, paints, in-world captures, the validation gate and handling. The list is generated from the roster data, so a new vehicle appears by being added.

Feedback: comment on a vehicle's page (which view or state, what to change). Each comment becomes a bug bead that cites the page and the car; nothing waits for a verdict (R126).
