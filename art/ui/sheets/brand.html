QR rule

qr-rule.svg: a real, scannable code for https://jammers.dilger.dev/j/ROO7. The room code sits beside it, never inside.

The rule

  • Plain black modules on pure white (#000000 on #FFFFFF). Never tinted, never inverted.
  • A quiet zone of at least 4 modules on every side. Nothing overlaps it.
  • Error correction M, square modules, nothing in the middle.
  • The room code goes beside the code in the display face, large enough to read across a room.

Minimum size

    Never put a logo in the middle.
    Never trim the 4-module quiet zone.
    Never invert or tint: black on white only.
