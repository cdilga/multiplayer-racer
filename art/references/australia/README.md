# Australian biome references

- `raw/` — owner photos and real signs (ground truth for look).
- `generated/` — image-generated biome sheets: `biome-town`, `biome-rocks-olgas`, `biome-outback-dirt-and-bitumen`.
  `biome-rocks-olgas-incorrect-signs.png` is a negative example (wrong signs).
- Real sign designs: https://en.wikipedia.org/wiki/Road_signs_in_Australia (Wikimedia Commons).

Used by plan §11.5a (R83). References guide look and layout only; models are code-built (§12).
