KEY ALGORITHMS TESTED
=====================

DNF Ranking Formula:
  sort(vehicles) by:
    1. lap (desc)
    2. checkpoint (desc)
    3. distance to next gate (desc)
    4. last progress time (desc)
    5. seat ID (asc - display tiebreaker only)

  Example:
    Vehicle p1: 3 laps, finished=true
    Vehicle p2: 2 laps, checkpoint=5, 450m, 75s
    Vehicle p3: 2 laps, checkpoint=5, 450m, 74.5s
    Vehicle p4: 1 lap

    Rank: p1, p2, p3, p4 ✓

Late Join Eligibility Window:
  isActive = (joinTime < firstFinisherTime OR no first finisher)
          AND (timeSinceRaceStart <= 50% * expectedDuration)

  Examples:
    Join at 10% of 120s race: active ✓
    Join at 50% of 120s race: active ✓
    Join at 51% of 120s race: queue ✓
    Join after first finisher: queue ✓

Grace Timer Behavior:
  firstFinisherTime = t → graceStartTime = t
  graceExpiryTime = t + 30000ms (default, tunable)

  If all vehicles finished before expiry → end race early ✓
  If grace expires → transition to finished state with DNF rankings ✓
